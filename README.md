# ES 复盘练习 · TradingView 风格 K 线回放

基于 CME E-mini S&P 500 (ES) 1 分钟历史数据的**本地复盘练习工具**：随机/自选一段行情，
像 TradingView 的 Bar Replay 一样逐根播放，同时支持下单、持仓盈亏、交易记录统计。

> 当前版本 **v1.2.5**（2026-10-24）。逐版改动记录见文末 **[更新记录](#更新记录)**，或 `git tag` / 根目录 `VERSION` 文件。

## 快速开始

**前置条件**：Windows（`启动.vbs` 依赖 `pythonw.exe` + `MSXML.XMLHTTP`）、Python 3、
一份 ES 1 分钟原始 CSV（见下方「数据说明」）。**仓库里不含行情数据** —— 预处理产物约 300 MB，
放在 `data/` 且被 `.gitignore` 排除，clone 下来必须自己跑一遍 `preprocess.py` 才有 K 线可看。

1. 把原始 CSV 目录接到 `preprocess.py` 顶部的 `SRC`（现在写死成作者本机的路径），
   目录里放 `ES_*_1min.csv`，列为 `datetime,open,high,low,close,volume`（美东墙钟时间）。
   然后跑一次预处理 + 校验（约 47 秒）
   ```bash
   python preprocess.py && python validate.py
   ```
2. 双击 **`启动.vbs`**（无窗口后台启动本地服务器，并自动打开浏览器）
   - 服务器只绑定 `127.0.0.1`，默认端口 8899（被占用时自动顺延，实际端口见 `port.txt`）
   - 页面地址：`http://127.0.0.1:8899/`
3. 在开始弹窗中选择模式/周期/时段，点 **开始复盘**
4. 用完点页面右上角 **退出**（或双击 `停止.vbs`）停止服务器

> 服务器与页面均只在本机运行，不联网、不上传任何数据。
>
> **注意**：`启动.vbs` / `停止.vbs` 必须保持纯 ASCII 内容。Windows 的 VBScript
> 按系统 ANSI 代码页读取 .vbs，文件里混入 UTF-8 中文会导致字节错位、脚本静默
> 损坏（曾因此出现"缺少对象 'sh'"报错）。如需修改这两个文件，请勿加入中文。

### 图标：从参考截图里描出来的，不是照着画的

手写 SVG 路径永远只是"像"，做不到一样。所以 `trace_icons.py` 直接对
`reference/17-TV-收藏条真实尺寸-2026-10-21.png` 里图标的墨迹做矢量化：

1. 取灰度覆盖率场 `(255-v)/255`，用 **marching squares** 抽 0.5 等值线（借抗锯齿做亚像素定位）
2. 鞍点（case 5/10）按四角均值消歧 —— 不处理的话 45° 细线会被切成一串小菱形（趋势线的斜线就这么丢过）
3. 每条闭合环塞进一个 path，配 `fill-rule="evenodd"`，圆环内白 / 方框内白自动镂空
4. 坐标约定 `viewBox "0 0 56 56"` 渲染 28 CSS px ⇒ **1 单位 = 0.5 CSS px**，与原图 2x 一一对应

```
python trace_icons.py    # 描轮廓 -> _icons_tv.json
python apply_icons.py    # 写进 index.html，可重复运行
```

### 性能：鼠标交互期的热路径

- **十字光标跨 K 线才更新图例**：在同一条 K 线内上下移动时不再重写 OHLC / 涨跌幅 / 成本价等
  8~10 个 DOM 节点（这是之前"鼠标发滞"的主因）；图例更新再用 `requestAnimationFrame` 合并到一帧
- 值没变就不写 DOM（`_setText`）；鼠标悬停时按 `time → 下标` 查表，不再线性扫几千根
- `getBoundingClientRect()` 结果缓存，尺寸变化/滚动/窗口缩放才失效
- 缩放/平移引起的重绘用 `requestAnimationFrame` 合并，一帧最多画一次绘图层
- 交易记录列表用内容签名判重，没有新成交就不重建 DOM；持仓均价线价格没变就不销毁重建
- 实测（1500×860 视口）：单次绘图层全量重绘 **0.08 ms**；同列上下移动 60 次 → 图例只重算 **1 次**、
  DOM 写入 **13 次**（优化前是 60 次图例 + 600+ 次 DOM 写 + 60 次全表扫描）；空闲/播放/拖动/缩放均 **60 fps**

### 绘图工具怎么用（两点点击，与 TradingView 一致）

1. 点工具（趋势线 / 水平线 / 矩形 / 尺子 / 斐波那契）
2. **左键点第一点 → 松开 → 移动鼠标 → 再点第二点**，图形完成（不是按住拖）
3. `水平线` / `文字` 单击即完成；文字会弹出内联输入框，回车确认
4. **画到一半点右键 = 取消这次绘制**（不弹挂单菜单）；`Esc` 也可取消
5. 光标模式下**点中已有图形**可拖动（端点或整体平移）；选中后按 `Delete` 删除
6. **鼠标中键直接点图形就删掉**（不用先左键选中再按 Delete）；中键点空白处不做任何事
7. 图形之间**可以互相叠压**：后画的在上，点中任何一个就把它提到最上层
8. `磁吸` 吸附到最近 K 线的开高低收；`隐藏` 临时收起全部绘图
9. **全图有效**：落点和拖动都支持右侧/左侧空白区（还没画出 K 线的地方也能画），
   坐标按「一根 K 线的间隔」逻辑外推，日线及以上同样适用
10. `尺子` 照参考截图画：**淡蓝填充框 + 过中心的十字线（顶端↑、右端→）+ 蓝色三行标签**
   —— `变化值 (百分比) tick数` / `N根K线, 时长` / `成交量 X K`；只保留最新一次测量
10. `趋势线` 按住 **Shift** 画 = **强制水平**
11. 顶栏 `↶ ↷` 撤销 / 重做绘图操作

### 价格行为学工作流：右键突破单 + 拖线止盈止损

1. 在图上**点右键** → 菜单显示该价位与时间
2. `挂突破买单`（上破触发）/ `挂突破卖单`（下破触发）→ 图上出现一条**可拖动的触发线**
   - 拖动这条线即可调整入场价，标签实时显示 `突破买 1手`
3. 价格穿越触发线即成交（**跳空时按开盘价成交**，更接近真实滑点）
4. 成交后在入场价上出现**一组标签**（照参考截图）：
   `做多 / 做空` 彩色实心胶囊 · `TP` 青色虚线圆 · `SL` 橙色虚线圆 ·
   `◀ | N | 0.00 USD | ✕` 各一条线一块牌子（贴价格轴，颜色跟随方向）
   - 三个圆形/胶囊只是按钮外观；真正的止盈/止损是另外两条**可拖动的虚线**
   - 拖 `止盈/止损` 虚线即时改价，价格触到就自动平仓并计入盈亏
5. 右键菜单还有 `市价平仓` / `撤销全部挂单` / `清除止盈止损`

### 价格行为 setup 统计（v1.1 / v1.2）

练习价格行为学最需要的不是"赚了多少"，而是"**哪种做法在赚钱、哪种在赔钱**"。所以每一笔
交易都要在两个**互相独立**的维度上打标：

| 维度 | 取值 | 说明 |
|---|---|---|
| **市场周期** | 突破 / 窄通道 / 宽通道 / 区间 | Al Brooks 的四阶段循环，判断"现在是什么市" |
| **Setup** | **每个周期各有一份清单**（默认 3–5 个 + 「感觉」） | 判断"这一笔按什么入场" |

#### 每个市场周期一份独立清单（v1.2）

4 个周期的入场本来就不一样，所以**清单按周期分开存**——同一个 setup 也可以同时属于多个周期
（比如 `H2 / L2` 在突破和宽通道里都用）。

下单弹窗是**左右两栏**：

| 位置 | 内容 | 怎么用 |
|---|---|---|
| 左栏 | **全局参考库**：库里的全部 setup，按分组列出 | **点一下**就加进右边当前周期的清单；已经在本周期的会灰显打勾，点不动 |
| 右栏 | **当前周期在用**的清单，按分组列出 | 点名字 = 选它下单；点 `×` = 只从本周期移出（**setup 本身不删**，库里还在） |

- **顶部 4 个周期按钮**切换；没选周期时右栏是空的（逼着先选，因为周期是必选维度）。
- **新建的 setup 同时进全局库，但只勾给当前周期** —— 这样以后在别的周期也能从左栏点到它，
  不用重敲一遍名字。
- **分组完全可自定义**：「官网 Top 10 / 反转 / 回调 / 旗形 / 其他」都能**改名、新增、删除**。
  删分组时组里的 setup **一个都不删**，会落到「未分组」等重新归位。
- **管理弹窗**（弹窗底部「管理」）里，每个 setup 一行：`改名 · 分组下拉 · 启用 · 适用周期（4 个勾选）`。
  勾上哪个周期就出现在哪个周期的清单里。

默认分配（可以随便改）：

| 周期 | 默认带的核心 setup |
|---|---|
| 突破 | 突破 · 最终旗形 · H2/L2 · 突破回调 · 缺口 |
| 窄通道 | 突破 · 最终旗形 · H1/L1 |
| 宽通道 | H2/L2 · 三推 · M2B · M2S · EMA 回调 |
| 区间 | MTR · 区间反转 · 磁力位 · 双底 · 双顶 |

「感觉」四个周期都带（它是说不出具体形态时的兜底，不算在核心名额里）。`通道` / `MM 测量移动` /
`开盘反转` / `高潮反转` / `双底牛旗` / `双顶熊旗` / `突破失败` 一开始不在任何周期里，
留在左栏参考，用得上时点一下就加。

- **必选，没选就弹窗拦**：点买入/卖出、按 `B`/`S`、按 `↑`/`↓`、右键挂突破单，只要这一笔会
  **从空仓开新仓**，就必须先在弹窗里选好 `市场周期 + Setup`，选完立刻执行刚才那笔下单。
- **每单都要重新选**：setup 用完即清（防止"上一单的标签被习惯性带过来"）；
  市场周期会留在面板上（一个阶段里不常变）。
- **加仓 / 减仓不重复打标**：沿用本笔已有的 setup，只记 `加仓次数`。
- **反手已取消**：反向下单只平到现有仓位，超出的部分直接丢弃并提示 —— 想反手就分两次做，
  这样一笔交易永远只有一条干净记录。

#### 一笔交易 = 一笔记录

账本的单位是 **空仓 → 回到空仓**，不是成交流水。平完最后一手时自动结算成一条，记录里带：

`Setup` · `市场周期` · `方向` · `周期` · `时段` · `入场/出场时间与价格` · `手数` · `加仓次数` ·
`点数` · `初始风险(点)` · **`R`** · `美元` · `初始止盈/止损` · `出场原因` · `是否拿到初始止盈` · `跳空成交`

#### R 的口径（分母锁定，不重算）

```
R = 盈亏点数 ÷ 初始风险点数          初始风险 = |入场价 − 初始止损|
```

- **市价单**：入场当根内可以随便拖止盈止损；**进入下一根 K 线的那一刻锁定**（等于"你当时
  打算用多少点赌这一笔"）。锁定后再挪止损 / 加仓，分母都不变 —— 不锁定的话，事后把止损
  挪到 1 个 tick，"R 收益"就会虚高。
- **突破单**：挂单时就把 `止损（前 5 根极值外 1 tick）` 和 `止盈（2R）` 一起挂出来，三条线
  都能拖；**成交瞬间锁定**成这一笔的初始风险。
- 出场原因自动判别：`tp` / `sl` / `trail_tp`（手动拖过止盈）/ `trail_sl`（拖过止损）/ `manual`（手动平）。

#### 账本存三层，断电不丢

| 层 | 位置 | 作用 |
|---|---|---|
| ① | `localStorage` | 即时写入，关浏览器/关机都不丢 |
| ② | `data/journal.json` | 自动原子写盘（临时文件 + rename），清缓存/换浏览器能整本读回 |
| ③ | 手动导出 | CSV（Excel 直接算）/ JSON（完整备份，可再导入合并） |

合并规则一律**按 id 去重，同 id 以新导入的为准**，绝不覆盖已有记录。

#### 统计面板（交易记录右边的页签）

- **综合**：胜率 / 平均 R / 总 R / 总点数
- **按 Setup**：逐个 setup 的 n / 胜率 / 均 R，按样本量排序，底部一行「全部」
- **按市场周期**：同上，用来验证"四种市况里我到底在哪一种赚钱"
- **突破挂单成交率**：按 setup 统计 `成交 / 撤单 / 未触发`，独立于盈亏（挂单本身也有价值）
- **n < 20 标灰加 `*`** 并注明「参考价值有限」—— 别拿 3 笔的胜率当结论
- 统计口径是**全部场次**（这才是"过往的单子"的意义）；「交易记录」页签只显示**本场**，
  标题写成 `(本场/累计)`；`清空交易记录` 只清本场，不碰历史

### Bar Count（当日序号）

- 按**交易日**重置：RTH 以自然日、ETH 以 CME 交易日（18:00 ET 起算），**开盘第一根 = 1**
- 默认**每 2 根显示一次**（显示 2/4/6…，1/3/5 不显示）；缩得很小时自动稀疏到每 4/8 根
- 图例里的 `Bar Count` 显示当前那根（或悬停那根）的当日序号

### 视窗：K 线靠左 2/3，右侧 1/3 留空

- **刚进来 / 换一段 / 换周期 / 换时段 / 按 R 重置**，最后一根都停在横向 **2/3** 处，
  右边留出 **1/3** 空白（`ChartMgr.RIGHT_BLANK = 0.5`，即空白 = 有 K 线部分的一半）
- 留白足够时回放推进**不会推着画面走**：新 K 线直接填进右侧空白，视窗不动；
  等填到右端才开始整体跟随 —— 与 TradingView 的 right offset 行为一致
- 你自己拖到别处后，切周期只按时间锚点重定位，不会把视窗重置回默认

## 数据说明

- 原始数据：2007-09-20 ~ 2026-07-24 的 ES 1 分钟 K 线（美东时间墙钟，含 DST）
- 主力合约：按 CME 交易日成交量自动选取（H/M/U/Z 季度循环），共切换 74 次
- 复权：**加法向后复权**，切换点残差 0.0000 点，连续序列无跳空
- 2007-09~12 为合约挂牌爬坡期较稀疏，随机复盘默认从 2008-01 开始
- 前端加载的是预处理后的二进制 gz 文件（`data/` 目录，由 `preprocess.py` 生成），
  10 个周期 × ETH/RTH 共 ~814 个文件；浏览器端解压解析，无外部依赖
- **时间轴恒显示美东时间**：图表时间戳按"ET 墙钟编码成假 UTC"生成，刻度与十字光标
  全部用 UTC 方法格式化，换机器/换时区都不会偏移（早期版本靠本地时区换算，在 GMT+8 机器上会偏 8 小时）

## 已知边界

- 交易模拟以**触发价/当时 K 线收盘价**成交（回放工具的固有近似），不模拟盘口深度与手续费
- 突破单在"推进到满足条件的 K 线"时成交；**跳空时按该根开盘价成交**
- 止盈止损同一根内都被触及时，按**止损优先**（保守处理）
- 限价单在"推进到满足条件的 K 线"时成交；回退时光倒流，已成交限价单不会重复成交
- EMA20 用窗口内 context(400 根)递推，与全历史精确值有极小差异（回放场景可忽略）
- Bar Count 在窗口首根若落在日内中间，用"距开盘时间 ÷ 周期"估算序号；窗口内其余 bar 逐根累加
- 用 **Go to** 跳到当前窗口之外会重新加载数据并**重置交易记录与绘图**（价格上下文已完全不同）
- **持仓中不允许换行情 / 结束复盘 / 清空**（会先提示"请先平仓，点右侧面板的平仓"），否则这一笔的 R 就丢了。
  例外：图表还没加载时（重开页面、还没点开始）一律放行 —— 那时候没有价格可平仓，拦下去就无路可走
- 持仓按 `sessionId` 做**归属校验**：存档记录的场次与当前不一致（或者老存档压根没有归属字段）时，
  这个持仓在恢复阶段就会被丢弃。丢掉不损失记录 —— 它本来就没平仓，账本里也没有它
- R 的分母在"进入下一根"（市价单）/ "成交瞬间"（突破单）锁定；当根内就平仓的单，
  用当根止损补算，标记为 `manual` 出场
- 突破挂单有 `barsAlive` 概念：**没走过一根就撤单 = 视为没挂过**，不进账本；
  但只要成交了就一定记（哪怕下一根立刻打穿）

## 更新记录

> 倒序，最新在上。每一条都是当时真实做过、并用 `tests/e2e.js` 守住的改动。

> **版本 v1.2.5**（2026-10-24）· 版本号同时记在仓库根目录 `VERSION` 文件与 git tag `v1.2.5` 上。
>
> v1.2.5 让**入场与出场的成交箭头分得开**：入场仍是青绿 `#70ccbd` / 红 `#cc2f3c`，
> **出场一律灰 `#787b86`**。
> - 起因：用户「入场出场你都会给我标记那俩箭头，但是箭头的颜色是固定的，出场和入场有时候分不清」
> - 为什么不靠形状/透明度区分：箭头只有 **16.5×19 CSS px**（`reference/21` 那张图是 2x，
>   逐像素实测过），塞不下文字；空心描边仅 1.75px，两根 K 线挨近时只剩个小洞，像「变淡」而不是
>   「空心」；半透明在**白底**上 34% 的青绿几乎看不见，且随底色变。**颜色是唯一稳定的第三重信号**。
> - 为什么灰：方向（朝上=买 / 朝下=卖）+ 位置（K 下 / K 上）已经两重编码了买卖，颜色这一层
>   就空出来专标「开还是收」，而且不跟涨跌色打架（红/绿已被 K 线阴阳、盈亏占满）。取的是项目里
>   `--text-dim` 的同一个色值，不引入新色相。
> - 判据来自 `Trading.fill()` 返回的 `closed`：它 >0 就说明这次成交平掉了仓位。`fill` 内部
>   「同向=加仓 `opened` / 反向=平仓 `closed`」互斥，不会两边都算。突破单成交那条路径原来不带这个
>   信息，`checkBar` 的 `fill` 事件里补了 `closed`（持仓中挂的反向突破单就是用来平仓的）。
> - **顺手修掉一个旧 bug**：`closePosition()` 里 `addMarker(Trading.pos > 0 ? 'sell' : 'buy', …)`
>   是在 `fill()` **之后**读 `Trading.pos`，而那时仓位已归零 → 平空仓的箭头一直错画成「买」
>   （K 下朝上）。改成 fill 之前先定 `side`。
> - **没做**：入场→出场的淡虚线连线（能解决「哪两个箭头是一笔」的归属，但斜线会横穿 K 线，
>   长持仓会拉很长）。用户明确「先不加」。

> v1.2.4 重做底栏日号条：**从「最近 5 天」改成「上周一整周 + 本周」的固定 5 列网格**。

> 第一格永远是周一、第五格永远是周五，两周之间一根竖线。

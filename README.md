# ES 复盘练习 · TradingView 风格 K 线回放

基于 CME E-mini S&P 500 (ES) 1 分钟历史数据的**本地复盘练习工具**：随机/自选一段行情，
像 TradingView 的 Bar Replay 一样逐根播放，同时支持下单、持仓盈亏、交易记录统计。

## 快速开始

1. 双击 **`启动.vbs`**（无窗口后台启动本地服务器，并自动打开浏览器）
   - 服务器只绑定 `127.0.0.1`，默认端口 8899（被占用时自动顺延，实际端口见 `port.txt`）
   - 页面地址：`http://127.0.0.1:8899/`
2. 在开始弹窗中选择模式/周期/时段，点 **开始复盘**
3. 用完点页面右上角 **退出**（或双击 `停止.vbs`）停止服务器

> 服务器与页面均只在本机运行，不联网、不上传任何数据。
>
> **注意**：`启动.vbs` / `停止.vbs` 必须保持纯 ASCII 内容。Windows 的 VBScript
> 按系统 ANSI 代码页读取 .vbs，文件里混入 UTF-8 中文会导致字节错位、脚本静默
> 损坏（曾因此出现"缺少对象 'sh'"报错）。如需修改这两个文件，请勿加入中文。

### K 线配色：白涨黑跌（价格行为学）

- **阳线 = 空心**（背景色填充 + 深色边框），**阴线 = 实心深色** —— 就是阿尔·布鲁克斯
  《价格行为交易》里用的黑白盘面，避免红绿干扰读结构
- 深色主题镜像：阳线空心（深底亮框）、阴线实心亮色
- 成交标记、最新价线、EMA、尺子统一走墨色；**Bar Count 序号是橙色**（参考截图即橙色）
- **没有成交量副图**（参考截图没有，用户明确不需要）

### 界面配色：国际惯例（绿 = 多/涨/盈利，红 = 空/跌/亏损）

- `--long: #089981` / `--short: #f23645`，浅色与深色主题一致，**不再按中国市场习惯翻转**
- 右侧下单面板：`买入` 绿、`卖出` 红；浮动/已实现/合计盈亏 **盈绿亏红**；交易记录同理
- 图例的涨跌幅（`+0.75 (+0.02%)`）也跟随：涨绿跌红
- 图例 `500` 徽标与小旗仍是红色（照参考截图，属于品牌元素，不参与涨跌语义）

### 图标：从参考截图里描出来的，不是照着画的

手写 SVG 路径永远只是"像"，做不到一样。所以 `trace_icons.py` 直接对
`reference/17-TV-收藏条真实尺寸-2026-10-21.png` 里图标的墨迹做矢量化：

1. 取灰度覆盖率场 `(255-v)/255`，用 **marching squares** 抽 0.5 等值线（借抗锯齿做亚像素定位）
2. 鞍点（case 5/10）按四角均值消歧 —— 不处理的话 45° 细线会被切成一串小菱形（趋势线的斜线就这么丢过）
3. 每条闭合环塞进一个 path，配 `fill-rule="evenodd"`，圆环内白 / 方框内白自动镂空
4. 坐标约定 `viewBox "0 0 56 56"` 渲染 28 CSS px ⇒ **1 单位 = 0.5 CSS px**，与原图 2x 一一对应

```
python trace_icons.py    # 描轮廓 -> _icons_tv.json
python apply_icons.py    # 写进 index.html，可重复运行
```

覆盖 24 个图标：收藏条 9 个 + 左侧工具栏 15 个（画笔没有对应原图，仍是我们自己的图标）。

### 性能：鼠标交互期的热路径

- **十字光标跨 K 线才更新图例**：在同一条 K 线内上下移动时不再重写 OHLC / 涨跌幅 / 成本价等
  8~10 个 DOM 节点（这是之前"鼠标发滞"的主因）；图例更新再用 `requestAnimationFrame` 合并到一帧
- 值没变就不写 DOM（`_setText`）；鼠标悬停时按 `time → 下标` 查表，不再线性扫几千根
- `getBoundingClientRect()` 结果缓存，尺寸变化/滚动/窗口缩放才失效
- 缩放/平移引起的重绘用 `requestAnimationFrame` 合并，一帧最多画一次绘图层
- 交易记录列表用内容签名判重，没有新成交就不重建 DOM；持仓均价线价格没变就不销毁重建
- 实测（1500×860 视口）：单次绘图层全量重绘 **0.08 ms**；同列上下移动 60 次 → 图例只重算 **1 次**、
  DOM 写入 **13 次**（优化前是 60 次图例 + 600+ 次 DOM 写 + 60 次全表扫描）；空闲/播放/拖动/缩放均 **60 fps**

### 绘图工具怎么用（两点点击，与 TradingView 一致）

1. 点工具（趋势线 / 水平线 / 矩形 / 尺子 / 斐波那契）
2. **左键点第一点 → 松开 → 移动鼠标 → 再点第二点**，图形完成（不是按住拖）
3. `水平线` / `文字` 单击即完成；文字会弹出内联输入框，回车确认
4. **画到一半点右键 = 取消这次绘制**（不弹挂单菜单）；`Esc` 也可取消
5. 光标模式下**点中已有图形**可拖动（端点或整体平移）；选中后按 `Delete` 删除
6. **鼠标中键直接点图形就删掉**（不用先左键选中再按 Delete）；中键点空白处不做任何事
7. 图形之间**可以互相叠压**：后画的在上，点中任何一个就把它提到最上层
8. `磁吸` 吸附到最近 K 线的开高低收；`隐藏` 临时收起全部绘图
9. **全图有效**：落点和拖动都支持右侧/左侧空白区（还没画出 K 线的地方也能画），
   坐标按「一根 K 线的间隔」逻辑外推，日线及以上同样适用
10. `尺子` 照参考截图画：**淡蓝填充框 + 过中心的十字线（顶端↑、右端→）+ 蓝色三行标签**
   —— `变化值 (百分比) tick数` / `N根K线, 时长` / `成交量 X K`；只保留最新一次测量
10. `趋势线` 按住 **Shift** 画 = **强制水平**
11. 顶栏 `↶ ↷` 撤销 / 重做绘图操作

### 收藏工具条

图例右侧那条白色圆角悬浮条 —— **按住左边的六点柄可以拖到任意位置**，位置会记住。
工具按钮悬停有深色气泡提示。

### 价格行为学工作流：右键突破单 + 拖线止盈止损

1. 在图上**点右键** → 菜单显示该价位与时间
2. `挂突破买单`（上破触发）/ `挂突破卖单`（下破触发）→ 图上出现一条**可拖动的触发线**
   - 拖动这条线即可调整入场价，标签实时显示 `突破买 1手`
3. 价格穿越触发线即成交（**跳空时按开盘价成交**，更接近真实滑点）
4. 成交后在入场价上出现**一组标签**（照参考截图）：
   `做多 / 做空` 彩色实心胶囊 · `TP` 青色虚线圆 · `SL` 橙色虚线圆 ·
   `◀ | N | 0.00 USD | ✕` 各一条线一块牌子（贴价格轴，颜色跟随方向）
   - 三个圆形/胶囊只是按钮外观；真正的止盈/止损是另外两条**可拖动的虚线**
   - 拖 `止盈/止损` 虚线即时改价，价格触到就自动平仓并计入盈亏
5. 右键菜单还有 `市价平仓` / `撤销全部挂单` / `清除止盈止损`

### Bar Count（当日序号）

- 按**交易日**重置：RTH 以自然日、ETH 以 CME 交易日（18:00 ET 起算），**开盘第一根 = 1**
- 默认**每 2 根显示一次**（显示 2/4/6…，1/3/5 不显示）；缩得很小时自动稀疏到每 4/8 根
- 图例里的 `Bar Count` 显示当前那根（或悬停那根）的当日序号

### 视窗：K 线靠左 2/3，右侧 1/3 留空

- **刚进来 / 换一段 / 换周期 / 换时段 / 按 R 重置**，最后一根都停在横向 **2/3** 处，
  右边留出 **1/3** 空白（`ChartMgr.RIGHT_BLANK = 0.5`，即空白 = 有 K 线部分的一半）
- 留白足够时回放推进**不会推着画面走**：新 K 线直接填进右侧空白，视窗不动；
  等填到右端才开始整体跟随 —— 与 TradingView 的 right offset 行为一致
- 你自己拖到别处后，切周期只按时间锚点重定位，不会把视窗重置回默认

### 快捷键

`空格` 播放/暂停 · `←/→` 步进 · `R` 回到起点 · `B` 买入 · `S` 卖出 · `C` 市价平仓 ·
`Delete` 删除选中绘图 · `右键` 突破单/平仓菜单 · `Esc` 取消绘图工具 / 结束复盘

## 数据说明

- 原始数据：2007-09-20 ~ 2026-07-24 的 ES 1 分钟 K 线（美东时间墙钟，含 DST）
- 主力合约：按 CME 交易日成交量自动选取（H/M/U/Z 季度循环），共切换 74 次
- 复权：**加法向后复权**，切换点残差 0.0000 点，连续序列无跳空
- 2007-09~12 为合约挂牌爬坡期较稀疏，随机复盘默认从 2008-01 开始
- 前端加载的是预处理后的二进制 gz 文件（`data/` 目录，由 `preprocess.py` 生成），
  10 个周期 × ETH/RTH 共 ~814 个文件；浏览器端解压解析，无外部依赖
- **时间轴恒显示美东时间**：图表时间戳按"ET 墙钟编码成假 UTC"生成，刻度与十字光标
  全部用 UTC 方法格式化，换机器/换时区都不会偏移（早期版本靠本地时区换算，在 GMT+8 机器上会偏 8 小时）

## 已知边界

- 交易模拟以**触发价/当时 K 线收盘价**成交（回放工具的固有近似），不模拟盘口深度与手续费
- 突破单在"推进到满足条件的 K 线"时成交；**跳空时按该根开盘价成交**
- 止盈止损同一根内都被触及时，按**止损优先**（保守处理）
- 限价单在"推进到满足条件的 K 线"时成交；回退时光倒流，已成交限价单不会重复成交
- EMA20 用窗口内 context(400 根)递推，与全历史精确值有极小差异（回放场景可忽略）
- Bar Count 在窗口首根若落在日内中间，用"距开盘时间 ÷ 周期"估算序号；窗口内其余 bar 逐根累加
- 用 **Go to** 跳到当前窗口之外会重新加载数据并**重置交易记录与绘图**（价格上下文已完全不同）

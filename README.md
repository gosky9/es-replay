# ES 复盘练习 · TradingView 风格 K 线回放

基于 CME E-mini S&P 500 (ES) 1 分钟历史数据的**本地复盘练习工具**：随机/自选一段行情，
像 TradingView 的 Bar Replay 一样逐根播放，同时支持下单、持仓盈亏、交易记录统计。

## 快速开始

1. 双击 **`启动.vbs`**（无窗口后台启动本地服务器，并自动打开浏览器）
   - 服务器只绑定 `127.0.0.1`，默认端口 8899（被占用时自动顺延，实际端口见 `port.txt`）
   - 页面地址：`http://127.0.0.1:8899/`
2. 在开始弹窗中选择模式/周期/时段，点 **开始复盘**
3. 用完点页面右上角 **退出**（或双击 `停止.vbs`）停止服务器

> 服务器与页面均只在本机运行，不联网、不上传任何数据。
>
> **注意**：`启动.vbs` / `停止.vbs` 必须保持纯 ASCII 内容。Windows 的 VBScript
> 按系统 ANSI 代码页读取 .vbs，文件里混入 UTF-8 中文会导致字节错位、脚本静默
> 损坏（曾因此出现"缺少对象 'sh'"报错）。如需修改这两个文件，请勿加入中文。

## 界面与操作

- **顶栏**：`ES1! · 周期 · CME` → 周期快捷切换(1m/5m/15m/30m/1H/4H/1D/1W + ▾ 10m/12h)
  → 指标(EMA20 开关) → ETH/RTH 时段 → 右侧 主题切换 / 随机复盘 / 自选复盘 / 退出
- **收藏工具横条**（图表上方，TradingView 的 Favorites 栏）：
  `光标` `趋势线` `水平线` `垂直线` `矩形` `斐波那契回撤` `文字` `测量尺` ｜
  `磁吸` `隐藏/显示` `删除全部` ｜ `Bar Count`
- **左侧工具栏**：同一套绘图工具 + `磁吸` `隐藏/显示` `删除全部` `重置缩放` `显示全部` `截图` `清除交易` `快捷键`
  （两侧按钮**高亮联动**，点哪边都一样）
- **图表左上图例**：`ES1! · 周期 · CME` + `O H L C` + 涨跌幅 + `Vol` + 持仓 + `EMA` + `Bar Count`
- **悬浮回放条**（图表底部中央，TradingView Bar Replay 样式）：
  `⏮ 起点` `◀ 上一根` `▶/⏸ 播放` `▶ 下一根` `⏭ 跳到末尾` ｜ `Speed 0.5x~60x` ｜
  `Go to 日期时间` ｜ `Bar count 已播放/总数` ｜ `当前K线时间` ｜ `✕ 结束复盘`
- **右侧面板**：下单（市价/限价、多空、手数）· 持仓与盈亏 · 交易记录

### 绘图工具怎么用

1. 点工具（趋势线 / 水平线 / 垂直线 / 矩形 / 斐波那契 / 测量尺），对话框不再弹出
2. 在图上**按住左键拖出**形状，松手即完成，工具自动回到光标（与 TradingView 一致）
3. `文字` 工具：点一下出现内联输入框，回车确认
4. 光标模式下**点中已有图形**可拖动（端点或整体平移）；选中后按 `Delete` 删除
5. `磁吸` 开启后端点吸附到最近 K 线的开高低收；`隐藏` 临时收起全部绘图（含 Bar Count 以外）
6. `测量尺` 显示 **点数 / 百分比 / 跨越几根 K 线**，只保留最新一次测量
7. `Bar Count` 开关控制 K 线下方橙色序号 + 图例里的指标行

### 快捷键

`空格` 播放/暂停 · `←/→` 步进 · `R` 回到起点 · `B` 买入 · `S` 卖出 · `C` 市价平仓 ·
`Delete` 删除选中绘图 · `Esc` 取消绘图工具 / 结束复盘

| 收藏工具横条 | 图表上方横排绘图工具（TV 的 Favorites 栏） |
| 左侧工具栏 | 竖排图标栏：绘图工具 + 磁吸/隐藏/删除 + 缩放/截图/清除 |
| 绘图工具 | 趋势线 / 水平线 / 垂直线 / 矩形 / 斐波那契回撤(7 级) / 文字 / 测量尺，可拖拽编辑、按 Delete 删除 |
| Bar Count | K 线下方橙色序号（按缩放自适应稀疏）+ 图例指标行，可开关 |
| 图例 | 左上角：`ES1! · 1m · CME` + `O H L C` + 涨跌幅 + `Vol` + `EMA` + `Bar Count` |
| 坐标轴 | 右侧价格轴（彩色最新价标签 + 持仓均价虚线）、底部时间轴 + 日期分隔 |
| 成交量 | 独立底部 pane，红/绿随涨跌 |
| Bar Replay | 悬浮胶囊工具条（播放组 / Speed / Go to / Bar count / 关闭） |
| 水印 | **已移除** TradingView 左下角 logo |
| 视窗行为 | 拖动/缩放后步进**不再回弹**；跟随态新 bar 自动进入视窗；播放时从右侧留白推入 |
| 交互 | 滚轮缩放、拖动平移、双击重置、十字光标虚线 + 轴标签、EMA20 |
| 配色 | 取 TradingView 色值：红 `#f23645` / 绿 `#089981`（默认按中国习惯映射为涨红跌绿） |

**仍不同（有意取舍）**

| 项目 | 现状 |
|------|------|
| 绘图工具深度 | 无 TV 的画笔/箭头/射线族/艾略特/江恩等扩展工具，也无单图形样式面板（颜色/线宽）；现有 7 类覆盖复盘练习需求 |
| 绘图的跨周期 | **切换周期/时段会清空绘图**（时间轴刻度变了，时间锚点无法映射）；TV 会重映射 |
| 指标 | 只有 EMA20 + Bar Count（复盘练习够用），无多指标叠加与参数面板 |
| 品种 | 固定 ES 连续序列，无多品种切换、无真实行情/账户/盘口 |
| 时间轴 | 无 TV 的多级自适应刻度与周末压缩（lightweight-charts 内置行为） |
| 数据滚动 | 窗口式加载（当前点前 400 根 + 后 3000 根），不能无限向前回拖；用 Go to 换段 |
| 交易 | 本地模拟，成交价=当根收盘价，无滑点/手续费/保证金 |

## 数据说明

- 原始数据：2007-09-20 ~ 2026-07-24 的 ES 1 分钟 K 线（美东时间墙钟，含 DST）
- 主力合约：按 CME 交易日成交量自动选取（H/M/U/Z 季度循环），共切换 74 次
- 复权：**加法向后复权**，切换点残差 0.0000 点，连续序列无跳空
- 2007-09~12 为合约挂牌爬坡期较稀疏，随机复盘默认从 2008-01 开始
- 前端加载的是预处理后的二进制 gz 文件（`data/` 目录，由 `preprocess.py` 生成），
  10 个周期 × ETH/RTH 共 ~814 个文件；浏览器端解压解析，无外部依赖

## 目录结构

```
es-replay/
├── 启动.vbs / 停止.vbs     无窗口启动/停止(pythonw + MSXML.XMLHTTP, 纯 ASCII)
├── server.py               本地静态服务器(禁缓存, /__shutdown, 日志落盘)
├── index.html / css/ / js/ 前端(lightweight-charts v5 本地 vendor)
├── data/                   预处理后的二进制数据(meta.json 为索引)
├── preprocess.py           数据预处理(主力拼接→复权→10 周期聚合)
├── validate.py             数据校验脚本
├── tests/e2e.js            Playwright 端到端测试(47 项)
├── tests/visual_check.js   视觉核验截图(绘图/Bar Count/主题)
└── server.log              服务器访问日志
```

## 重新生成数据 / 跑测试

```bash
# 数据预处理(约 47 秒) + 校验
python preprocess.py
python validate.py

# 端到端测试(需先启动服务器)
node tests/e2e.js
```

## 已知边界

- 交易模拟以**当时 K 线收盘价**成交（回放工具的固有近似），不模拟滑点与盘口
- 限价单在"推进到满足条件的 K 线"时成交；回退时光倒流，已成交限价单不会重复成交
- EMA20 用窗口内 context(400 根)递推，与全历史精确值有极小差异（回放场景可忽略）
- 用 **Go to** 跳到当前窗口之外会重新加载数据并**重置交易记录**（价格上下文已完全不同）
